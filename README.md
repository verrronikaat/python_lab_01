Лабораторная работа №1 по дисциплине «Теория алгоритмов».
Тема: «Введение в язык программирования Python».

## О проекте

Репозиторий содержит 11 учебных заданий по основам Python:
работа со словарями, списками, кортежами, множествами, строками и срезами.

Все задания обёрнуты в функции и покрыты автотестами (`pytest`).
Есть верхнеуровневый модуль `main.py` с интерактивным меню.

## Структура проекта

```text
python_lab_01/
├── 00_distance.py          # расстояния между городами
├── 01_circle.py            # площадь круга и точка внутри
├── 02_operations.py        # расстановка знаков операций (1 2 3 4 5 → 25)
├── 03_favorite_movies.py   # срезы строки с фильмами
├── 04_my_family.py         # список семьи и общий рост
├── 05_zoo.py               # работа со списком животных
├── 06_songs_list.py        # сумма длительностей песен
├── 07_secret.py            # расшифровка сообщения срезами
├── 08_garden.py            # множества цветов
├── 09_shopping.py          # магазины с минимальными ценами
├── 10_store.py             # подсчёт стоимости товаров на складе
├── main.py                 # верхнеуровневый модуль с меню
├── test_lab.py             # тесты pytest

## Требования

- Python 3.10+
- pip

## Установка и запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/verrronikaat/python_lab_01.git
   cd python_lab_01
(Опционально) создать и активировать виртуальное окружение:

python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
Установить зависимости:
pip install -r requirements.txt
Запустить главный модуль с меню:
python main.py
Меню позволяет выбрать конкретное задание (1–11), выполнить все (all) или выйти (q).

Либо запустить отдельное задание напрямую:
python 00_distance.py
python 01_circle.py
...
Тестирование
Запуск тестов:
pytest -v
Ожидается 20 passed — тесты покрывают все 11 заданий.
